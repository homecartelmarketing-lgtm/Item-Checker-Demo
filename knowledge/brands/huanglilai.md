# Huanglilai (黄利莱) Supplier Catalog Conventions

## Model Numbering Scheme
Huanglilai uses alphanumeric model numbers where suffix indicates size and shape:
- Example: `DD249863-1000长`
  - `DD249863`: Design series code (faceted crystal crown design)
  - `1000`: 1000mm (100cm) length
  - `长` (Cháng): Denotes **Elongated / Rectangular** shape
- Circular variants in the same series:
  - `DD249863-800圆` or `D800`: 80cm diameter circular chandelier with 1 central hanging cord.
  - **Important QC Warning**: Suppliers frequently bundle the circular photo into the gallery of the rectangular SKU. These MUST be flagged as **MISMATCH**.
